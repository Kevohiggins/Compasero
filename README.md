# Compasero

**Secuenciador de letras por compases musicales y metrónomo en tiempo real.**

Compasero es un programa diseñado para músicos que necesitan desplazar automáticamente las letras de sus canciones mientras tocan su instrumento.

Es pa' ciegos, no te voy a mentir.

Compasero funciona 100% por estructura musical (BPM, compases y tiempos) y está optimizado para lectores de pantalla.

---

## Características Principales

- Modo Simple: Configuración directa por compases (4/4, 3/4, 6/8, etc.), velocidad en BPM, calibración por Tap Tempo y selección de múltiples tiempos de disparo por compás.
- Compás de Cuenta Inicial: El primer compás al iniciar marca el pulso de metrónomo sin mover el cursor, permitiéndote escuchar la entrada y que el lector de pantalla lea la primera línea.
- Guion Avanzado por Compases: Armá la estructura completa de tu tema alternando bloques de `Bajar Letra` e `Instrumental / Silencio`.
- Plantillas de Canciones: Guardá y cargá prospectos de canciones en archivos de texto plano. Incluye plantillas automáticas para Chacarera, Zamba y Balada/Rock 4/4.
